## New / Enhanced Exports & ABI Notes (100% Backwards-Compatible, Zero Header Edits)

### 1. mfplat_xs.dll (src/shims/mfplat_shim.cpp)
- New export:
  * `MFCreateMediaEngineClassFactory(void** ppFactory)` -> returns COM `IMFMediaEngineClassFactory` (`CreateInstance`, `CreateTimeRange`, `CreateError`) creating `IMFMediaEngine` / `IMFMediaEngineEx` instances with exact event ordering (`LOADSTART -> LOADEDMETADATA -> CANPLAY -> PLAYING -> TIMEUPDATE -> ENDED`), D3D12/DXGI/IMFMediaBuffer `TransferVideoFrame`, and headless/CI NV12/RGBA synthesis fallback.
- Enhanced existing exports:
  * `MFCreateDXGIDeviceManager` & `MFResetDXGIDeviceManagerX`: wraps host `IMFDXGIDeviceManager` so Xbox `ID3D12Device` binding succeeds on Windows 10/11 & CI (`ResetDevice`, `OpenDeviceHandle`, `CloseDeviceHandle`, `LockDevice`, `UnlockDevice`, `TestDevice` with `MF_E_DXGI_NEW_VIDEO_DEVICE` on reset, `GetVideoService`).
  * `MFTEnumEx`: adds clean-room H.264 (`MFVideoFormat_H264`) and HEVC (`MFVideoFormat_HEVC`) video decoder `IMFActivate` fallback when host MFTs are absent (e.g., headless CI or Windows 10 without HEVC extensions).
  * `MFCreateAttributes` / `MFCreateMemoryBuffer`: added clean-room fallbacks when host `mfplat.dll` is absent.
- Zero `__uuidof` usage and dynamic `oleaut32.dll` `SysAllocString` resolution (portable across MSVC, Clang-CL, and MinGW-w64).

### 2. XAudio2_9.dll (src/shims/xaudio2_shim.cpp)
- New exports (effect-chain & headless clock helpers preserving `IXAudio2Voice` primary COM vtable):
  * `OpenScarlettXAudio2SetEffectChain(IXAudio2Voice* pVoice, const void* pEffectChain)`
  * `OpenScarlettXAudio2EnableEffect(IXAudio2Voice* pVoice, uint32_t EffectIndex, int32_t Enable)`
  * `OpenScarlettXAudio2GetEffectState(IXAudio2Voice* pVoice, uint32_t EffectIndex, int32_t* pEnabled)`
  * `OpenScarlettXAudio2SetEffectParameters(IXAudio2Voice* pVoice, uint32_t EffectIndex, const void* pParameters, uint32_t ParametersByteSize)`
  * `OpenScarlettXAudio2GetEffectParameters(IXAudio2Voice* pVoice, uint32_t EffectIndex, void* pParameters, uint32_t ParametersByteSize)`
  * `OpenScarlettXAudio2AdvanceClock(IXAudio2* pXAudio2, uint32_t frame_count, uint64_t* out_total_frames_mixed)`
- Engine hardening:
  * Real submix bus mixing ordered by `ProcessingStage`, dangling-submix reference cleanup on `DestroyVoice`, multi-send routing, and real Reverb APO (4-comb stereo Schroeder DSP) + VolumeMeter APO (per-channel Peak & RMS) execution.
  * Frame-accurate `OnVoiceProcessingPassStart` / `OnBufferStart` / `OnLoopEnd` / `OnBufferEnd` / `OnStreamEnd` / `OnVoiceProcessingPassEnd` delivery strictly outside mutexes, immediate end-of-buffer completion on the finishing quantum, `PlayBegin`-adjusted loop points, and atomic monotonic `SamplesPlayed`.
  * Replaced all `__uuidof(...)` WASAPI calls with inline `constexpr GUID`s for MinGW-w64 portability.

### 3. Bink2 Multi-Frame Streaming (src/middleware/bink2_decoder.cpp in openscarlett_core)
- New C ABI streaming helpers (zero-realloc plane decode & fast BT.709 conversion):
  * `OpenScarlettBink2StreamCreate(const uint8_t* data, size_t size, void** out_stream)`
  * `OpenScarlettBink2StreamDestroy(void* stream)`
  * `OpenScarlettBink2StreamSetLoop(void* stream, int32_t loop_enabled)`
  * `OpenScarlettBink2StreamSeek(void* stream, uint32_t frame_index)`
  * `OpenScarlettBink2StreamDecodeNextFrame(void* stream, uint32_t pixel_format, void* out_frame_view)`
  Delivers sequential RGBA8/BGRA8 + planar YCbCr (`plane_y`, `plane_cb`, `plane_cr`), synchronized 48 kHz audio packets when `audio_track_count > 0`, loop keyframe reset, and monotonic microsecond `pts_us`.

### 4. GameInput.dll (src/shims/gameinput_shim.cpp)
- New secondary COM interface via `IGameInput::QueryInterface` (`IID_OS_IGameInputEx = {5CA01001-4254-445A-9C09-FFC40F006919}`):
  * `RegisterDeviceCallback`, `StopCallback`, `UnregisterCallback`
- New C ABI exports:
  * `OpenScarlettGameInputRegisterDeviceCallback(...)`
  * `OpenScarlettGameInputStopCallback(IGameInput* input, uint64_t callbackToken)`
  * `OpenScarlettGameInputUnregisterCallback(IGameInput* input, uint64_t callbackToken, uint64_t timeoutInMicroseconds)`
  * `OpenScarlettGameInputSimulateDeviceHotPlug(IGameInput* input, uint32_t deviceSlot, GameInputKind supportedInput, int32_t connected, IGameInputDevice** outDevice)`
  * `OpenScarlettGameInputGetDeviceForKind(IGameInput* input, GameInputKind inputKind, IGameInputDevice** outDevice)`
  * `OpenScarlettGameInputGetDeviceRumbleTelemetry(IGameInputDevice* device, void* outTelemetry)`
  * `OpenScarlettGameInputGetUiNavigationState(IGameInputReading* reading, void* outState)`
- Per-device timestamped reading history ring buffers (128 entries/device + 256 global) for simultaneous Gamepad + Keyboard + Mouse + UiNavigation, plus LT/RT impulse-trigger rumble blending into XInput vibration and recorded telemetry.
