## Modified Files
- include/openscarlett/io/dstorage_abi.h
  - Added OS_DSTORAGE_E_STAGING_BUFFER_TOO_SMALL, OS_DSTORAGE_E_STAGING_BUFFER_INVALID, OS_DSTORAGE_E_CANCELLED
  - Added DSTORAGE_MIN_STAGING_BUFFER_SIZE (64 KiB), DSTORAGE_DEFAULT_STAGING_BUFFER_SIZE (32 MiB), DSTORAGE_MAX_STAGING_BUFFER_SIZE (256 MiB)
  - Added DSTORAGE_QUEUE_STATS, OpenScarlettDStorageGetQueueStats, OpenScarlettDStorageGetStagingBufferSize, OpenScarlettDStorageDecompressWithIntermediate
- src/shims/dstorage_shim.cpp
  - Implemented submitted & in-flight request cancellation (atomic mid-read & pre-commit cancellation with untouched destinations, clean stats & status completion)
  - Enforced staging / intermediate_size bounds validation in SetStagingBufferSize, ExecuteRequest, and OpenScarlettDStorageDecompressWithIntermediate
  - Implemented direct decompression into kernelx/xmem physical-page destinations (dynamic QueryTitlePhysicalPages + XMemSize resolution, VirtualQuery committed-writable range validation, zero-copy GDeflate to physical pages)
- src/shims/xcrdapi_shim.cpp
  - Added XCrdValidateIntermediateBuffer and XCrdDecompressToBuffer (intermediate_size bounds validation + physical-page destination writability check + GDeflate/BCPack/None decompression)
  - Preserved fail-closed E_NOTIMPL on XCrdStartMiniDumpCapture and XCrdUploadCrashDump
- include/openscarlett/kernel/kernelx_abi.h
  - Added XMemAllocAligned, XThreadSetAffinityMask, XThreadSetPriority, XThreadGetPriority, KERNELX_THREAD_PRIORITY_ERROR_RETURN
- src/shims/kernelx_shim.cpp & src/shims/kernelx_mingw.def
  - Added deterministic XMem edge-case handling (zero-size alloc, invalid memtype/alignment, integer overflow guards, duplicate free LastError preservation across CallTelemetry, out-of-range physical page guards)
  - Added XThreadSetAffinityMask (Scarlett 14-core affinity folding + invalid handle/mask handling), XThreadSetPriority (deterministic priority clamping), XThreadGetPriority, and invalid handle validation in SetThreadName/GetThreadName
- src/shims/xmem_shim.cpp & src/shims/xmem_mingw.def
  - Added XMemAllocAligned forwarding and accurate duplicate-free error telemetry on XMemFree / XMemFreeDefault
- include/openscarlett/audio/xaudio2_abi.h
  - Added OS_XAUDIO2_ENDPOINT_PROBE, OpenScarlettXAudio2ValidateEndpointIdW, OpenScarlettXAudio2ValidateEndpointIdA, OpenScarlettXAudio2ProbeWasapiEndpointW
- src/shims/xaudio2_shim.cpp
  - Added full Windows MMDevice endpoint ID validation/normalization (NULL/empty/"default", canonical {0.0.0.00000000}.{guid}, WinRT/PnP \\?\SWD#MMDEVAPI#{...}[#{iface-guid}], bare {guid}, wide & narrow)
  - Wired validated endpoint selection into IXAudio2::CreateMasteringVoice and WasapiRenderLoop (with graceful default-endpoint fallback and fast stop-flag teardown checks)
- src/audio/opus_adpcm_decoder.cpp
  - Added RFC 6716 Opus sample-rate validation and IMA-ADPCM block-parameter guards
