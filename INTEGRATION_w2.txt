4. THIN MERGE HOOKS FOR `src/gpu/d3d12_xs/command_queue_x.cpp`
--------------------------------------------------------------
A. `CommandQueueX::ExecuteCommandLists` (`command_queue_x.cpp`, ~line 694):
   - Before invoking `host_queue_->ExecuteCommandLists(NumCommandLists, host_lists)`:
     If `device_x_` has active `TitleVAMirror` regions, record a lightweight pre-submission
     dirty-page flush command list via `device_x_->GetTitleVaMirror().FlushDirtyPagesToGpu(pre_cmd, 0ull)`
     and prepend `pre_cmd` to the submitted batch only when `flush_stats.regions_flushed > 0`.
     (Zero overhead when all pages are clean: `clean_skips` fast path emits no GPU copy!)

B. `CommandQueueX::Signal` (`command_queue_x.cpp`, ~line 1068) & fence-completion polling:
   - When guest code waits on a signaled fence or during `PresentX` fence completion
     (`WaitForInternalFenceWithTimingLocked`, ~line 1650), invoke:
       device_x_->GetTitleVaMirror().CompleteReadbacksOnFence(completed_fence_val);
     This synchronizes any scheduled GPU->CPU readbacks back into guest Title-VA CPU memory
     and resets Win32 write-watch on the overwritten pages so readback writes never trigger
     false CPU dirty uploads on the next frame.

C. RDNA2 Shader Bindless Dispatch Hook (`CommandListX` / `DeviceX`):
   - Before Dispatch / Draw on lifted RDNA2 shaders that consume raw V#/T#/S# via root SGPRs
     `s0..s15`, bind `device_x_->GetDescriptorBridge().BindHeapsToCommandList(host_cmd)` and
     pass deduplicated bindless indices (SM 6.6 `ResourceDescriptorHeap[idx]` when
     `SupportsSm66DirectHeapIndexing()` is true, or SM 6.5/6.2/5.1 unbounded descriptor-table
     binding pointing at `GetResourceHeapGpuStart()` / `GetSamplerHeapGpuStart()`).
